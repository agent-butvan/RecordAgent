# 空会话概览

## 展示与导航

- `ChatWorkspace` 完成历史加载且没有消息时显示概览；加载中和加载失败仍使用原来的状态页面。
- 首条用户消息追加后切换到聊天内容，已有消息的会话直接显示历史；概览不创建聊天消息。
- 输入框保留在滚动区域下方；概览隐藏空会话的步骤轨，两列卡片随可用宽度缩为一列，适配侧栏和右侧面板。
- 日历、财务、学习记录入口沿用主页面导航。资料支持打开列表、新建和打开指定资料，继续使用原有编辑器。

## 卡片与数据口径

| 卡片 | 现有数据源 | 统计与操作 |
| --- | --- | --- |
| 今天要做 | `dailyEvents` 的当日日记录 | 未完成优先，再按优先级和时间排列；最多展示五项。复用待办清单，通过事件版本与发生日期更新循环待办。 |
| 收支一览 | `financeApi` 的 overview 与月度 expense-chart | 今日支出取完整每日汇总，不从最近流水推算；本月收支与收益直接使用后端统计。支持记账和流水详情；没有账户时引导到财务页添加。 |
| 资料积累 | `recordApi` 的资料和分类 | 日期范围与资料页一致（前后各一年），排除归档和回收站。今日按 recordDate 统计，最近三篇按 updatedAt 排序，点击进入编辑器。 |
| 学习足迹 | `studyApi` 的活动学习、近七日统计和分类 | 时长和片段数使用后端按时区计算的结果，不重复叠加进行中时长。支持开始、结束学习，与现有学习窗口同步事件。 |

“帮我安排今天”将当前未完成待办放入输入框并聚焦，由用户确认发送。顶部新建记录复用日历表单；保存失败保留表单内容，提交期间禁止重复操作。写手记进入资料编辑器并预选手记类型。

## 扩展与状态

- `common/OverviewCard` 基于现有 `Card`，统一标题、说明、操作位、正文、页脚、加载和可重试错误状态；业务内容通过 `children` 扩展，不包含业务请求或页面状态。
- `chat/overview` 仅负责空会话概览及其局部状态；所有请求继续经过 `services`，不新增接口、存储或依赖。
- 各卡片独立加载与重试，失败不会显示虚构的零值。重新进入概览、窗口恢复焦点时刷新；跨本地日期重新统计；活动学习每分钟及收到跨窗口事件时刷新。
- 异步加载忽略卸载和旧请求结果；待办保存包含版本检查并限制同条目重复提交。

## DOX 复核

沿用前端组件、服务、类型的现有职责与 CSS Modules 规范；未改变全局工程规则、权限、后端接口和持久化位置，无需新增子级 AGENTS.md。通用待办清单新增可选删除回调及保存禁用状态；日历快捷表单支持等待异步保存，兼容现有调用。
